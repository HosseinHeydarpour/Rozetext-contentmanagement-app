# Rozetext Instagram Content Management App
## سیستم مدیریت و تقویم محتوای اینستاگرام با همگام‌سازی محلی کامپیوتر و موبایل

پروژه جامع مدیریت، برنامه‌ریزی و زمان‌بندی پست‌های اینستاگرام شامل:
- **سرور محلی کامپیوتر (`server/`)**: سرور محلی بر پایه Node.js و Express با داشبورد وب فارسی، تقویم شمسی، پوشه پایش خودکار (`watch_folder`)، استریم ویدیو با پشتیبانی از HTTP Range، و تولید کد QR برای اتصال آسان گوشی.
- **اپلیکیشن اندروید فلاتر (`mobile_app/`)**: دارای نمای تقویم روزانه شمسی (امروز / فردا / آینده)، نمای شبکه ۳×۳ پروفایل اینستاگرام، پخش‌کننده ویدیو داخلی، یادآور اعلان محلی، و دانلود ۱-کلیکه ویدیو در گالری همراه با کپی خودکار کپشن.

---

### 🚀 شروع سریع

#### ۱. اجرای سرور روی کامپیوتر
روی فایل `start_server.bat` دابل کلیک کنید.
- آدرس داشبورد کامپیوتر در مرورگر: `http://localhost:3000`
- آدرس اتصال گوشی و کد QR در کنسول نمایش داده می‌شود.

#### ۲. اجرای اپلیکیشن اندروید
راهنمای کامل نصب فلاتر و خروجی APK در فایل [SETUP_GUIDE.md](SETUP_GUIDE.md) قرار دارد.
```bash
cd mobile_app
flutter pub get
flutter run
```
یا ساخت فایل نصبی:
```bash
flutter build apk --release
```

### 📂 ساختار پروژه
```
├── start_server.bat          # اجرای ۱-کلیکه سرور کامپیوتر
├── SETUP_GUIDE.md            # راهنمای جامع فارسی و انگلیسی
├── server/                   # سرور نودجی‌اس و داشبورد وب
│   ├── server.js             # API، استریم ویدیو و QR کد
│   ├── watcher.js            # مانیتور خودکار پوشه watch_folder
│   ├── public/               # داشبورد تحت وب
│   └── watch_folder/         # پوشه پایش فایل‌های ویدیویی
└── mobile_app/               # اپلیکیشن فلاتر اندروید
    ├── lib/                  # کدهای Dart برنامه
    └── android/              # تنظیمات بیلد اندروید
```
